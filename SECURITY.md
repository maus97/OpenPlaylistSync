# Security Policy

## Supported version

Security fixes are applied to the latest release and the current `main` branch.
Run a current image and review release notes before upgrading.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** private-reporting form for this
repository. Do not open a public issue containing exploit details, tokens,
credentials, playlist data, or other private information.

Include the affected version or commit, deployment model, reproduction steps,
impact, and any safe proof of concept. Do not test against systems or provider
accounts you do not own or control. Maintainers will acknowledge a complete
report as soon as practical and coordinate validation and disclosure.

If GitHub private vulnerability reporting is unavailable, open a public issue
that asks for a private contact channel without including vulnerability details.
