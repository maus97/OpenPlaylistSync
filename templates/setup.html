SETUP GUIDE

Connect your music services.

This is a one-time browser setup. You will add two developer apps, save their details in OPS, then sign in to each service.

1

Spotify

  1. Open the Spotify Developer Dashboard ↗ and create an app.
  2. In the app settings, add this redirect address exactly:

http://127.0.0.1:8000/auth/spotify/callback

  1. Enable the Web API if Spotify shows the option.
  2. Copy the Client ID and Client Secret into Settings.
  3. Save, open Playlists, and select Connect Spotify.

OPS asks for private playlist read/write access and basic account access for catalogue searches. It never asks for your Spotify password.

2

YouTube Music

  1. Open Google Cloud Console ↗ and create or select a project.
  2. Enable YouTube Data API v3 ↗.
  3. In Credentials ↗, create an OAuth client for TVs and Limited Input devices.
  4. Copy its Client ID and Client Secret into Settings.
  5. Save, open Playlists, and select Connect YouTube Music. Follow the code shown by OPS.

OPS requests the Google youtube scope so it can read and change playlists. It never asks for your Google password.

AFTER CONNECTING

Create your first pair

  1. Open Playlists and choose one playlist from each service. Select Create a new … playlist in either list when you need an empty side.
  2. Choose the first-sync option. The recommended merge option adds missing tracks only.
  3. Review the proposed changes. The first sync will never remove tracks.
  4. Later deletions are shown clearly and require you to type the confirmation phrase before OPS applies them.
