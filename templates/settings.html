ACCOUNT SETUP GUIDE

Create the two OAuth clients

browser only

You create the developer applications in the providers' websites, then paste the resulting client values into the form below. OPS never asks for your Spotify or Google account password.

01

Spotify

  1. Open the Spotify Developer Dashboard ↗ and choose Create an App.
  2. Open the app settings and add this exact redirect URI:

http://127.0.0.1:8000/auth/spotify/callback

  1. Copy the app's Client ID and Client Secret into the Spotify fields below.
  2. Save this page, then use Connect Spotify on the Pairs page.

OPS requests private and collaborative playlist read access plus private and public playlist write access.

02

YouTube Music

  1. Open Google Cloud Console ↗ and create or select a project.
  2. Enable YouTube Data API v3 ↗.
  3. Open Credentials ↗, create an OAuth client ID, and choose TVs and Limited Input devices.
  4. Copy the client ID and secret into the YouTube Music fields below.
  5. Save this page, then use Connect YouTube Music on the Pairs page.

OPS opens Google's verification page and displays a one-time code. Approve access there, then return to OPS and select “I completed authorization”.

Access requestedSpotify: playlist read/write scopesYouTube Music: https://www.googleapis.com/auth/youtube read/write scope
