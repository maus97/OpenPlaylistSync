Connect and sync

  1. Save the provider details above, then open Playlists and connect each service.
  2. Choose an existing playlist or create a new empty playlist on either service, then create the pair.
  3. Choose the first-sync option and review every proposed change. The first sync only adds tracks.
  4. Later removals require review unless you enable automatic sync for that pair.
