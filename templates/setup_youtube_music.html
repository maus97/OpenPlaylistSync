YOUTUBE MUSIC GUIDE

Connect YouTube Music.

Google uses several setup screens. Follow these steps in order, then OPS will guide you through the device approval.

1

Create or choose a Google Cloud project

  1. Open Google Cloud project setup ↗.
  2. Create a project for OPS, or select an existing personal project. Keep the project name handy; all later Google screens must use this same project.
2

Configure the OAuth consent screen

  1. Open Google Auth Platform / OAuth consent screen ↗ for the project.
  2. Choose External for a personal Google account. Enter an app name such as Open Playlist Sync, your support email, and your developer contact email.
  3. On the Audience or Test users screen, add the Google account that owns your YouTube Music playlists. Save each step.
  4. If Google shows an unverified-app warning during sign-in, choose the option to continue. That is expected for a private personal app that has not gone through verification.

Testing-mode authorizations can expire after seven days. If Google later asks you to reconnect, repeat the OPS approval step.

3

Enable the YouTube API

  1. Open YouTube Data API v3 ↗ in the same project.
  2. Choose Enable. If Google asks you to enable billing or accept terms, follow that prompt for the project.
4

Create the OAuth client

  1. Open Credentials ↗, or choose Google Auth Platform → Clients in the newer console.
  2. Choose Create client and select TVs and Limited Input devices. Give it a name such as OPS, then create it.
  3. Copy the Client ID and Client secret into the YouTube Music fields on Settings, then save.

Do not create a Web application client for OPS. The device client is required because OPS uses Google's device-code sign-in flow.

5

Approve YouTube Music in OPS

  1. Open Playlists and choose Connect YouTube Music.
  2. OPS will show a Google verification URL and one-time code. Open the URL on a device with a browser, enter the code, select the same Google account, and approve the YouTube permission.
  3. Return to OPS and choose I completed authorization. OPS will then load your playlists.

OPS requests https://www.googleapis.com/auth/youtube.force-ssl so it can read, create, add to, and remove items from your playlists. It never receives your Google password.
