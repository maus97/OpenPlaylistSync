SPOTIFY GUIDE

Connect Spotify.

Create a small Spotify Web API app, copy its credentials into OPS, and approve access to your playlists.

1

Create the Spotify app

  1. Open the Spotify Developer Dashboard ↗ and sign in.
  2. Select Create app. Enter any app name and description, select Web API if asked, accept the Developer Terms, and create it.
2

Allow OPS to return from sign-in

  1. Open the new app, choose Settings or Edit settings, and find Redirect URIs.
  2. Add the address below exactly, then save. Do not replace 127.0.0.1 with localhost.

{{ redirect_uri|default('http://127.0.0.1:8000/auth/spotify/callback') }}

When OPS is behind an HTTPS reverse proxy, use that public HTTPS callback address instead and enter the same value in Settings.

3

Copy the two app values

  1. In the Spotify app overview, copy the Client ID.
  2. Open Settings, choose View client secret, and copy the Client Secret.
  3. Paste both into the Spotify fields on Settings, then save.

Treat the client secret like a password. Keep it in OPS or a password manager; never post it in chat or commit it to Git.

4

Approve your Spotify account

  1. Open Playlists and choose Connect Spotify.
  2. Review the requested permissions and approve them. OPS needs playlist read/write access and basic account access for catalogue searches.

Spotify Web API access requires a Premium account. OPS never receives your Spotify password.
